# Mira Cloud 账户门户首页

## 目标与范围

为 `/` 提供独立的账户门户，让用户了解账户、设备授权和账户安全，并进入登录或账户中心。`/login` 继续只负责登录；不增加注册或认证方式，也不改变本地功能与云服务的边界。

## 方案

讨论了账户门户与产品介绍两种用途。用户选择账户门户：重点为账户管理能力和操作入口，避免宣传尚未接入的服务。

## 页面设计

沿用现有黑白配色、排版变量和按钮组件。顶部品牌回到 `/`，账户入口根据会话状态显示登录或账户中心。主体为“你的 Mira 云端账户”标题、简短介绍和主操作，下方展示设备与授权、账户安全、关联服务三项能力。关联服务如尚未接入，明确标识状态，不提供虚假可用入口。移动端使用单列。

## 路由和会话

首页在所有会话状态下保留于 `/`，不自动跳转。未登录主按钮进入 `/login`，已登录进入 `/account`；恢复会话期间显示检查提示，无法确认会话时提供到 `/account` 的检查入口。登录页的现有重定向与退出登录跳转保持现有行为。

## 验证

调整首页的路由行为测试，覆盖未登录、已登录、会话不可用与检查中状态，验证首页无登录表单且入口目标正确。执行 `pnpm run check`，构建前端并核查桌面及移动布局。
